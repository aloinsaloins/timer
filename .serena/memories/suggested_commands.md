# Development Commands

## Frontend Development
```bash
cd frontend
npm run dev       # Start development server
npm run build     # Build for production
npm run preview   # Preview production build
npm test          # Run tests with Vitest
```

## Backend Development
```bash
cd backend
npm run dev       # Start development server with hot reload
npm run build     # Compile TypeScript to JavaScript
npm start         # Start production server
npm test          # Run tests with Jest
```

## Git Commands (Windows)
```bash
git status        # Check current changes
git add .         # Stage all changes
git commit -m     # Commit changes
git push          # Push to remote
git pull          # Pull from remote
git checkout      # Switch branches
```

## Windows Utilities
```bash
dir               # List directory contents (Windows equivalent of ls)
cd                # Change directory
type              # Display file contents (Windows equivalent of cat)
findstr           # Search text in files (Windows equivalent of grep)
where             # Find command location (Windows equivalent of which)
```

## Project Navigation
```bash
cd frontend       # Navigate to frontend
cd backend        # Navigate to backend
cd ..             # Go up one directory
```

## Testing Commands
```bash
# Frontend testing
cd frontend && npm test

# Backend testing
cd backend && npm test
```

## Build Commands
```bash
# Build both frontend and backend
cd frontend && npm run build
cd backend && npm run build
```

## 概要
日本の平均寿命統計に基づいて親との残り時間を可視化するWebアプリケーションを作成します。ユーザーは親の年齢、年間訪問日数、一緒に過ごす時間を入力して、残り時間の推定値を計算し表示します。ReactフロントエンドとNode.jsバックエンドを使用したモダンなWebアプリケーションとして構築されます。

## 技術コンテキスト
**言語/バージョン**: TypeScript 5.x / Node.js 20.x  
**主要な依存関係**: React 18、Express.js、Vite  
**ストレージ**: ユーザー設定用のローカルストレージ（MVPではバックエンドDBは不要）  
**テスト**: フロントエンド用Vitest、バックエンド用Jest  
**対象プラットフォーム**: モダンWebブラウザ（Chrome、Firefox、Safari、Edge）
**プロジェクトタイプ**: web - フロントエンド + バックエンド構造  
**パフォーマンス目標**: <100ms計算時間、即座のUI更新  
**制約**: クライアント側計算可能、レスポンシブデザイン必須  
**規模/スコープ**: シングルユーザーアプリケーション、約10画面/コンポーネント
